# Manuscript: International Journal of Communication Systems (Wiley)

Special issue *Next-Generation 6G Mobile Networks and Services: LLM-Enabled
Semantic Communications*.

| File | Content |
| --- | --- |
| `main.tex` | the manuscript; inputs the files below |
| `preamble.tex` | layout (standard LaTeX that follows the Wiley NJD look: AMA-style superscript citations, upper-case section heads, FIGURE/TABLE captions) |
| `frontmatter.tex` | title, authors (placeholder), abstract, keywords |
| `sec1_introduction.tex` … `sec7_conclusion.tex` | sections 1–7 |
| `endmatter.tex` | author contributions, acknowledgements, funding, conflict of interest, data availability |
| `references.tex` | the reference list (every entry checked against its publisher or arXiv record) |
| `figures/` | data figures, generated by `scripts/paper_figures.py` and `scripts/paper_figure_endpoint.py` from the result files |
| `diagrams/` | the two TikZ diagrams (sources and PDFs) |
| `numbers.json`, `NUMBERS.md` | every number the manuscript quotes, with its source file (`scripts/paper_numbers.py`) |

Build: `pdflatex main && pdflatex main` (twice, for the cross-references).
Regenerate figures and numbers from the result files:

```
python scripts/paper_numbers.py
python scripts/paper_figures.py --out paper/figures
python scripts/paper_figure_endpoint.py --tables results/gpt2_v0.4_six_seeds/tables --out paper/figures
```

Red text marks what only the authors can supply: names, affiliations, ORCID
iDs, contributions, acknowledgements and funding.

For submission, the journal's own template (WileyNJD, AMA reference style)
can be used instead of `preamble.tex`: the section files contain no layout
commands beyond standard LaTeX, `booktabs` tables and `algorithmicx`.
