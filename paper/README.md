# Manuscript: International Journal of Communication Systems (Wiley)

*Doubly Nested Semantic Communication: Rate-Nested Token Transmission and
Time-Nested Language-Model Memories for Drift-Resilient 6G Links*

Abraheem Rashid, Faisal Iradat, Waseem Iqbal (corresponding author), Yawar Abbas Bangash.

Special issue *Next-Generation 6G Mobile Networks and Services: LLM-Enabled
Semantic Communications*.

| File | Content |
| --- | --- |
| `main.tex` | the manuscript; inputs the files below |
| `preamble.tex` | layout (standard LaTeX following the IJCS article look: numbered citations, "n \| Title" headings, FIGURE/TABLE captions) |
| `frontmatter.tex` | title, authors, affiliations, correspondence, abstract, keywords |
| `sec1_introduction.tex` … `sec7_conclusion.tex` | Sections 1–7 |
| `endmatter.tex` | conflicts of interest, data availability statement |
| `references.tex` | the reference list, generated by `tools/make_references.py` (every entry verified online, see `REFERENCES_CHECK.md`) |
| `figures/` | data figures (PDF), generated from the result files by `scripts/paper_figures.py` and `scripts/paper_figure_endpoint.py` |
| `diagrams/` | the five TikZ diagrams (sources, shared style `bw_style.tex`, compiled PDFs) |
| `numbers.json`, `NUMBERS.md` | every number the manuscript quotes, with its source file (`scripts/paper_numbers.py`) |

Build: `pdflatex main && pdflatex main` (twice, for the cross-references).
A diagram is rebuilt with `pdflatex fig_<name>.tex` inside `diagrams/`.

Regenerate figures and numbers from the result files of the repository:

```
python scripts/paper_numbers.py
python scripts/paper_figures.py --out paper/figures
python scripts/paper_figure_endpoint.py --tables results/gpt2_v0.4_six_seeds/tables --out paper/figures
```
