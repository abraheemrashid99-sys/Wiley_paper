\noindent\textbf{\sffamily Abstract}\par\smallskip
\noindent Large language models (LLMs) allow a semantic receiver to decode text from few channel symbols, because the model shared by both ends predicts what the transmitter is likely to say. After deployment the content drifts, and keeping the receiver's knowledge aligned costs air time that is rarely accounted for. This paper presents doubly nested semantic communication (DN-SC), a token-level transceiver that is nested in rate and in time. Every token is sent as a prefix of a 16-symbol codeword with exact per-shell power control, so that the receiver can request further symbols only for the tokens it is unsure of; a frozen GPT-2 model is the prior of a Bayesian beam-search decoder; and three receiver memories---the conversation context, a logit bias and low-rank adapter slots---adapt the prior at three timescales. The return-link requests and every bit of memory synchronisation are charged in channel symbols. On a hierarchical drift stream (AG News and TeleQnA, AWGN, mean signal-to-noise ratio 10\,dB) with six seeds, DN-SC reaches 90\,\% token accuracy with 7.08 real channel symbols per token against 9.23 for a frozen fixed-rate receiver with the same decoder: a saving of 23.3\,\% with the request signalling included, observed on every seed ($p = 0.031$), and of 27.9\,\% (95\,\% confidence interval 21.6--31.7\,\%) when the audited messages are decoded free-running. The free context memory supplies about three quarters of the gain of the memories; the shipped memories pay for their synchronisation, relative to the context memory, only when one update serves more than about 6100 messages. The decoder, the protocol and the tests were fixed before the confirmatory runs, and the code and all result files are public.
