# Check of `results/gpt2` with the corrected code (version 0.3)

Six of the 37 published stream runs, repeated on real GPT-2 with the code of
version 0.3 from one clean revision, on the same kind of machine and with the
same library versions as the published runs.

- `stream/` — the six runs in compact form; `raw_streams.tar.gz` holds their
  full per-step logs.
- `TABLES.md`, `tables/`, `figures/` — generated from these six runs alone
  (one seed per method: no statistics can be read from them).
- `COMPARISON.md` — generated by `scripts/compare_results.py` against
  `results/gpt2`. Its verdict reads "CHECK NEEDED" because 31 runs and the
  base-corpus evaluations were not repeated here; for the six runs that
  were, every headline number agrees to the last printed digit.

What these runs show is written up in `results/gpt2/RESULTS.md`, section 11,
and `docs/REVIEW.md`, section E: the published numbers are reproduced bit
for bit, and the new measurements (signalling of the refinement requests,
free-running decoding of the same symbols) are a first look on seed 0, not a
result of the paper.
